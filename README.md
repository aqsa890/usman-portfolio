## 🚀 How to Run & Preview

### Option 1: Open Directly in Any Web Browser
Simply double-click or right-click `index.html` and choose **Open With Google Chrome / Safari / Edge / Firefox**.

### Option 2: Run a Local Development Server
From the project folder, run any of the following:

- **Using Python 3**:
  ```bash
  python3 -m http.server 8080
  ```
  Then open `http://localhost:8080` in your browser.

- **Using Node / npx**:
  ```bash
  npx serve .
  ```

This portfolio is 100% static and requires zero build steps or database configuration. It can be hosted for free on:
