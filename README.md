## 🚀 How to Deploy to Netlify (100% Ready)

This repository is pre-configured and 100% **Netlify Ready** out of the box!

### Option A: Drag & Drop (Fastest — 30 Seconds)
1. Go to [app.netlify.com/drop](https://app.netlify.com/drop).
2. Drag and drop the `usman-potfolio` folder directly into the browser window.
3. Your site will go live immediately with a free HTTPS URL (e.g. `muhammad-usman.netlify.app`)!

### Option B: Deploy via GitHub (Continuous Deployment)
1. Push this repository to GitHub:
   ```bash
   git remote add origin https://github.com/<your-username>/usman-portfolio.git
   git push -u origin main
   ```
2. Log in to [Netlify](https://app.netlify.com) and click **"Add new site" &rarr; "Import an existing project"**.
3. Select **GitHub** and choose the `usman-portfolio` repository.
4. Netlify will auto-detect `netlify.toml` settings:
   - **Build command**: *(leave blank)*
   - **Publish directory**: `.`
5. Click **"Deploy site"**. Every future `git push` will deploy automatically!
